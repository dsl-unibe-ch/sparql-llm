A natural-language interface to the Elites Suisses knowledge graph by the LESSH project (Université de Lausanne / Universität Bern). Ask in English or French about ~58,700 Swiss political, economic, academic and military figures from the 19th–20th centuries. The system generates SPARQL queries against the public endpoint using RAG over curated examples and dataset schema.
58,729 persons (crm:E21) ~10,000 birth events (crm:E67) Family relations (P96/P97) CIDOC CRM · SDHSS ontologies
