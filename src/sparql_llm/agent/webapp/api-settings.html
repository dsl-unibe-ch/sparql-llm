🔒 What happens to your API key

In short: your key is encrypted before it is stored, it is only sent to the provider you choose, and the full key is never shown again. However, this server has to be able to decrypt your key in order to use it, so you are trusting this server and the people who run it. The details and the risks are below.

Step by step

  1. Sending. Your browser sends the key to this server over an encrypted HTTPS connection.
  2. Checking. The server tests the key by asking your provider (at the Base URL above) for its list of models. If the test fails, nothing is saved.
  3. Storing. The key is encrypted (AES with an integrity check) and saved in the app's user database, linked only to your account. The unencrypted key is never written to disk or to the server logs.
  4. Using. When you chat, the server decrypts the key in memory and sends it only to your provider, together with your messages. To hide models that cannot be used here, the server also sends one tiny test request per model about every 6 hours. These use a few tokens on your account.
  5. Showing. This page only shows a masked version (for example sk-p…****k29H). The full key is never sent back to your browser. No page in the app, including the admin pages, shows the full key or lets other users use it.
  6. Removing. Remove Key deletes it from the database straight away.

Risks you should know about

  • This is not end-to-end encryption. The secret that decrypts your key is kept on the same server as the database, because the server needs it to use your key. Someone with full access to this server (its administrators, or an attacker who breaks into it) could recover your key. The encryption mainly protects you if a copy of the database file leaks on its own.
  • Your provider sees your chats. Your messages are sent to the provider you choose, and its own privacy and data-retention rules apply.
  • Custom Base URL. With the custom provider, your key is sent to whatever address you enter. Only enter addresses you trust.
  • Backups. If the server is backed up, an encrypted copy of your key may stay in older backups after you remove it.
  • Costs. Everything this app does with your key is billed to your account with the provider.

How to protect yourself

  • Create a separate key just for this app instead of reusing one you use elsewhere.
  • If your provider allows it, give that key a spending limit or budget.
  • When you stop using this app, or if you think the key has been misused, revoke it at your provider. That is the only way to be sure the key can no longer be used anywhere, including here.
