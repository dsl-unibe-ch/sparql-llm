Open sign-up as an option, the tokens each answer used, and fixes from the curators' feedback on [swiss-elites.dsl.unibe.ch](https://swiss-elites.dsl.unibe.ch).

## Get it

```sh
docker pull ghcr.io/dsl-unibe-ch/sparql-llm:0.3.0
```

`latest` points to this release from now on. If you run 0.2.0, pull the new image and run `docker compose up -d`. Your data volume works as it is.

## What's new

- **Sign-up (optional).** Set `ALLOW_SIGNUP=true` in `.env` and the sign-in page offers **Create one**. New accounts are always plain users. Sign-up is off by default: if you also set a shared `OPENAI_API_KEY`, everyone who signs up can use it. See [`docs/DOCKER.md`](https://github.com/dsl-unibe-ch/sparql-llm/blob/v0.3.0/docs/DOCKER.md).
- **Tokens per answer.** Under each answer the chat shows how many tokens it took, summed over every call to the language model. This helps users who pay for their own key.

## Fixes

- **The model list no longer waits on a slow model.** The page asks each model whether it supports tool calling before it shows the model list. A model that hung made every page load wait 20 seconds, and the model picker was missing until then. The list now waits 3 seconds at most. A model that hasn't answered by then is listed, and its check goes on in the background.
- **With MCP tools on, the answer shows the query that ran.** The model types its query again when it writes the answer and sometimes changed it. So the query in the answer could differ from the one that **Run or edit the query** opens. The answer now shows the query that ran. Both places match the results the answer is based on.
- **Plain hyphens and spaces.** Some models write non-breaking hyphens and spaces, for example in names like Perret-Gentil, and a name written that way doesn't match the data. The model's output and the chat input now use plain hyphens and spaces.

## Known limits

The limits listed for [0.2.0](https://github.com/dsl-unibe-ch/sparql-llm/releases/tag/v0.2.0) still apply. The MCP tools mode is still experimental.
