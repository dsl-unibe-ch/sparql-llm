The first release of the Data Science Lab (University of Bern) fork of [sparql-llm](https://github.com/sib-swiss/sparql-llm). It is the chat assistant behind [swiss-elites.dsl.unibe.ch](https://swiss-elites.dsl.unibe.ch), packaged so curators can run their own instance.

## Get it

```sh
docker pull ghcr.io/dsl-unibe-ch/sparql-llm:0.2.0
```

`latest` points to this release from now on. To set it up, follow [`docs/DOCKER.md`](https://github.com/dsl-unibe-ch/sparql-llm/blob/v0.2.0/docs/DOCKER.md). To add your SPARQL endpoint, follow [`docs/ONBOARDING.md`](https://github.com/dsl-unibe-ch/sparql-llm/blob/v0.2.0/docs/ONBOARDING.md).

## What's in it

- **Datasets in the browser.** One instance serves several datasets. On the `/admin` page you add a dataset, upload its three files, press Check and Rebuild, and then Publish. You don't need a developer or a server change.
- **Accounts.** Logins, invitations and three roles (user, curator, admin). The first admin comes from `.env`.
- **Your own LLM.** Each user can enter a key for any OpenAI-compatible provider, including an Ollama on the same machine. The operator can instead set one key for everyone. Without a key the chat says so; it doesn't fail.
- **One container.** It includes the vector store and runs as an unprivileged user. It has health checks at `/healthz` and `/readyz`. Data lives in one volume and the embedding model in another.
- **Safe to stop.** You can stop or restart the app at any time, even during a Rebuild. A Rebuild that stops halfway changes nothing. One that had started switching to the new index finishes the switch when the app starts again.
- **Outbound policy.** Addresses that users or curators enter can't reach your private network or the machine itself, even through a redirect. If you need an exception, list it in `OUTBOUND_ALLOW`.

## Requirements

Docker with Compose, about 4 GB of RAM and 5 GB of disk. On first start the app downloads an embedding model of about 2 GB, so allow up to 30 minutes.

## Known limits

- The Ollama recipe was tested on Docker Desktop. On Linux, the guide's advice to bind Ollama to the Docker bridge hasn't been tested yet.
- Crash safety was tested by killing the app during a Rebuild, and by simulating a power cut and a full disk. A real power cut hasn't been tested.
- The PyPI package `sparql-llm` is SIB's release, not this fork. Use the Docker image.
